# Map Estimate Calculator (MVP)

Веб-приложение для предварительного расчета благоустройства на Яндекс Карте.

## Что умеет MVP
- Показывает Яндекс Карту с поиском адреса.
- Рисует полигоны, линии и точки.
- Считает площадь, длину и количество.
- Формирует список объектов с выбором типа работ, ценой и суммой.
- Считает итоги сметы.
- Сохраняет проект в `localStorage`.
- Экспортирует/импортирует проект в JSON.

## 1) Куда вставить API-ключ Яндекс Карт
Откройте файл `config.js` и заполните поле `yandexMapsApiKey`:

```js
export const APP_CONFIG = {
  yandexMapsApiKey: 'ВАШ_API_КЛЮЧ',
  yandexMapsLang: 'ru_RU',
  mapInitialCenter: [55.751244, 37.618423],
  mapInitialZoom: 11,
  storageKey: 'mapEstimateCalculatorProject',
};
```

Если ключ пустой, карта может не загрузиться в зависимости от требований API.

## 2) Как запустить локально

Так как это статический проект без backend, достаточно любого статического сервера.

Пример через Python:

```bash
python3 -m http.server 8080
```

Откройте в браузере:

```text
http://localhost:8080
```

## 3) Как опубликовать на GitHub Pages

1. Создайте репозиторий и загрузите все файлы проекта в корень репозитория.
2. В GitHub откройте: **Settings → Pages**.
3. В **Build and deployment** выберите:
   - **Source**: `Deploy from a branch`
   - **Branch**: `main` (или `master`) / `/root`
4. Сохраните.
5. Через 1–3 минуты откройте URL из раздела Pages.

> Для домена GitHub Pages не нужен сервер: все расчеты выполняются в браузере.
